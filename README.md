## Temat projektu: API + admin panel do zarządzania parkingami

## Autor: Kacper Zabłudowski 50007

## Jak uruchomić projekt

1. Sklonuj repozytorium: git clone git@github.com:KPR23/parking-management-api.git
2. cd parking-management-api
3. git checkout frontend
4. cp .env.example .env
5. docker compose up


## Linki do interfejsów

Prisma Studio: http://localhost:5555 (podgląd bazy danych oraz manipulacja danymi)

Admin Panel: http://localhost:3000 (panel do zarządzania parkingami)  

Swagger: http://localhost:8000/api (interfejs do testowania API)
